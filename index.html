Essencial
📊 Dados vs Informação
Dados: Fatos brutos, isolados, sem contexto. São valores quantificados sem significado completo.

Informação: Dados processados, contextualizados e com significado relevante.
💡 Exemplo
Dado: "25", "São Paulo", "14:30"
Informação: "Temperatura de 25°C em São Paulo às 14:30"
🗂️ Tipos de Dados
Estruturados: Organizados em tabelas com linhas e colunas (SQL, Excel, CSV)

Semi-estruturados: Têm estrutura parcial com metadados (JSON, XML)

Não estruturados: Sem formato fixo (textos, imagens, vídeos, áudios)
💡 Exemplos
Estruturado: Planilha de vendas com colunas (produto, preço, data)
Semi-estruturado: Arquivo JSON de API
Não estruturado: Email, foto, vídeo do YouTube
💡 Dica de Prova
Lembre: XLSX é estruturado (tabelas), JSON/XML são semi-estruturados, e imagens/.jpg são não estruturados!

⚙️ ETL e Processamento de Dados
▼
Processo-Chave
🔄 O que é ETL?
Extract (Extrair) → Transform (Transformar) → Load (Carregar)

Transform é a etapa mais demorada! Consome maior parte do tempo do profissional.
🧹 Transformação de Dados
Etapas essenciais:
1. Limpeza: Remover inconsistências e erros
2. Transformação: Converter formatos, criar features
3. Garantia de qualidade: Validar dados processados

• CSV - Valores separados por vírgula
• JSON - JavaScript Object Notation (semi-estruturado)
• PDF - Documentos (não estruturado)
• JPYNB - Jupyter Notebook

📈 Estatística e Tipos de Variáveis
▼
Estatística
👥 População vs Amostra
População: Conjunto TOTAL de indivíduos em estudo
Amostra: Parte representativa da população

Parâmetros: Descrevem a população (fixos)
Estimadores: Calculados da amostra (variam)
🔢 Variáveis Quantitativas
Discreta: Valores inteiros, contáveis
→ Exemplo: Qtd de Filhos (0, 1, 2, 3...)

Contínua: Valores decimais, mensuráveis
→ Exemplo: Altura (1.75m), Peso (70.5kg), Renda (R$ 3.456,78)
🏷️ Variáveis Qualitativas
Nominal: Sem ordem natural
→ Exemplo: Estado Civil (solteiro, casado, divorciado), Cor

Ordinal: Com ordem natural
→ Exemplo: Satisfação (1-5), Faixa Etária (0-18, 19-30...), Escolaridade
📊 Outliers e Medidas
Outlier: Valor FORA do padrão esperado (anomalia)

Média: Sensível a outliers
Mediana: Robusta a outliers (mais confiável com valores extremos)
🎯 Macete para Prova
Pode ter .5?
SIM → Contínua (altura, peso, renda)
NÃO → Discreta (filhos, pessoas, carros)
📊 Visualização de Dados
▼
Visualização
📈 Tipos de Gráficos
Dispersão (Scatter): Pontos distribuídos em dois eixos
Histograma: Distribuição de frequências
Boxplot: Mostra mediana, quartis e outliers
Barras: Comparar categorias
📦 Boxplot (Diagrama de Caixa)
Linha central: MEDIANA (não é a média!)
Caixa: 1º e 3º quartis (50% dos dados)
Pontos nas extremidades: OUTLIERS
📖 Data Storytelling
Combina visualização + narrativa + contexto para contar histórias com dados
⚠️ Pegadinha Comum
A linha central do boxplot é a MEDIANA, NÃO a média!
🤖 Machine Learning e IA
▼
Machine Learning
🎓 Aprendizado Supervisionado
PRECISA de dados rotulados para treinar

Classificação: Prever categorias (spam/não spam)
Regressão: Prever valores numéricos (preço, temperatura)
💡 Exemplos
Classificação: Detectar fraude, diagnóstico médico
Regressão: Prever preço de imóvel, vendas futuras
🔍 Aprendizado Não Supervisionado
NÃO precisa de dados rotulados

Exemplo: K-Means (clusterização/agrupamento)
⚠️ Underfitting vs Overfitting
Underfitting: Modelo muito simples, não captura padrões
Overfitting: Modelo muito complexo, "decora" dados de treino mas falha em dados novos
🧠 Inteligência Artificial
IA existe desde 1950! ChatGPT (2022) é apenas aplicação recente.

LLM: Large Language Models (GPT, Claude)
NLP: Processamento de Linguagem Natural
Deep Learning: Subcategoria de ML usando redes neurais
🎯 Para Decorar
Classificação: Categorias (sim/não, spam/ham)
Regressão: Números (R$ 150,00, 25°C)
🔀 Git e Versionamento

Git
📝 Comandos Git Essenciais
git init - Inicializa repositório local
git add - Prepara arquivos (staging)
git commit - Salva alterações localmente
git push - Envia commits para GitHub

⚠️ git add NÃO envia automaticamente ao GitHub!
💻 Comandos Bash/Terminal
cd .. - Volta para pasta anterior (pasta pai)
ls - Lista arquivos visíveis
ls -a - Lista TODOS arquivos (incluindo ocultos)
🔄 Fluxo Git
1. git add (prepara)
2. git commit (salva local)
3. git push (envia pro GitHub)
